# Reviewing the Form Structure Builder

Thank you for taking a look. This is the tool the backend developer uses to define the structure
of a form (pages, sections, fields and their layout); the frontend developer builds the real form
from what it exports.

## Opening it

1. Open the link you received.
2. **The first visit can take about 3 minutes.** The test server sleeps when nobody uses it and
   has to start up. Leave the tab open; once it's running, pages load normally.
3. Sign in with the user name and password you received.

## What to try

Everyone can change everything — it's a test copy, so feel free to experiment.

- Open **Demo: loan application** from the page menu at the top left. It shows every kind of
  element: sections, a subsection inside a subsection, a "map" (a group of fields such as an
  address), and a "matrix" (fields laid out on a grid).
- Click a field's name to open its settings on the right: rename it, make it mandatory, add a
  help text, or edit the choices of a list.
- Use the green **+** buttons to add fields, subsections, maps or a matrix.
- In a matrix, **drag a field** onto another cell, or change its row, column, height and width in
  its settings. Try making a field span two columns.
- Use the arrows to reorder, and the red **✕** to delete (you'll be asked to confirm).
- Create your own page with **+ New page**.

## Good to know

- Other reviewers use the same data, so you may see their changes.
- If the demo page gets deleted, it comes back the next time the server starts.
- After a long break you may have to sign in again.

## Feedback

Anything confusing, missing or broken is useful — a sentence and, if you can, a screenshot. Please
send it to the person who gave you the link.
